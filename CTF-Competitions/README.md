# CTF Competitions

Notes from CTF competitions, including challenge categories, problem-solving approaches, and lessons learned.

## Suggested categories

- Web
- Forensics
- OSINT
- Linux / Miscellaneous
- Cryptography
- Reverse engineering
- Binary exploitation

## Publishing rules

Before publishing a write-up, check the event rules. Do not publish flags, solutions, or other restricted material while a competition is active or where the organizers prohibit disclosure. Keep private team information and credentials out of this repository.
