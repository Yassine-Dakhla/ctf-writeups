A personal collection of cybersecurity challenge notes, CTF write-ups, and lessons learned while developing practical security skills.

- [Cylab Security Academy](./Cylab-Security-Academy/README.md) — completed multiple CTF challenges and web security labs.
- [TryHackMe](./TryHackMe/README.md) — completed multiple rooms and practical cybersecurity exercises.
- [CTF Competitions](./CTF-Competitions/README.md) — notes from online CTF events.

## Write-up format

Where relevant, each write-up will include:

1. **Challenge** — name, platform, and category.
2. **Objective** — what the challenge asks you to achieve.
3. **Approach** — the reasoning and investigation process.
4. **Tools and commands** — what was used and why.
5. **Solution** — the steps that solved the challenge, when publication is permitted.
6. **What I learned** — key concepts and takeaways.
7. **Remediation** — for security vulnerabilities, how to prevent or fix them.

## Progress

I have completed multiple Cylab Security Academy challenges, completed multiple TryHackMe rooms, and reached Level 23 in OverTheWire Bandit. This repository is being built out to document selected challenges and lessons learned. Individual write-ups will be added as they are prepared.

## Responsible use

All exercises are performed in authorized training environments. Write-ups for active competitions or platforms will only be published when their rules permit sharing solutions. Never use techniques against systems without permission.

## Disclaimer

These notes are for education and defensive security learning. They are not an invitation to test systems without authorization.
